## Key Patterns & Insights

### What Top ML Portfolios Do

1. **Blog is the #1 differentiator** — Every famous ML researcher (Karpathy, Lilian Weng, Colah, Eugene Yan) is known for their blog, not their portfolio design
2. **Content over flash** — ~70% use light, minimal, academic styling. Let the work speak
3. **Publications section is expected** — With venue, year, citations, and PDF/Code links
4. **Interactive demos embedded** — HuggingFace Spaces, Streamlit, Gradio iframes
5. **Jekyll/Hugo dominate** — al-folio (15.4K stars) and academicpages (16.7K stars) are the go-to templates

### What Top Design Portfolios Do

1. **Typography carries the brand** — Serif + grotesk pairings (Roslindale + Graphik, Schnyder + Founders Grotesk)
2. **Case studies over galleries** — Simon Pan, Pratibha Joshi, Andrew Couldwell
3. **Radical restraint works** — Valentina Pastushenko (1 font, 3 colors), Ed Chao (no about page)
4. **Dark ≠ unprofessional** — 40% of top designer portfolios use dark themes
5. **Motion with purpose** — GSAP scroll animations, not gratuitous

### What Top Creative Portfolios Do

1. **The site IS the proof** — Bruno Simon's 3D world proves Three.js mastery without explaining it
2. **France dominates** — 60%+ of top creative devs are French
3. **Astro is emerging** — Joffrey Spitzer uses Astro + GSAP + Three.js with excellent PageSpeed
4. **WebGPU is next** — Bruno Simon and Samsy are already rebuilding with WebGPU
5. **GSAP is universal** — The most common animation library across all creative portfolios

### Tech Stack Trends

| Stack | Used By | Best For |
|-------|---------|----------|
| Next.js + Vercel | Brittany Chiang, Lee Robinson, Rauno Freiberg | Custom dev portfolios with blog |
| Astro + GSAP | Joffrey Spitzer | Content sites with subtle animation |
| Hugo | Lilian Weng, Eugene Yan | Blog-heavy academic sites |
| Jekyll (al-folio) | Thousands of academics | Quick academic setup |
| Plain HTML | Karpathy | When content is everything |
| Webflow + GSAP | Dennis Snellenberg, Stas Bondar, Eliot Besson | Designers who don't code |
| Three.js + custom | Bruno Simon, Lusion, Samsy | Creative developers |

### Design Principles That Work

1. **One navigation layer, not four** — Top portfolios have a single, clear nav
2. **Sans-serif body, mono for code only** — Readability first
3. **Dark theme + single accent color** — Purple, green, teal, or blue
4. **Content hierarchy** — Featured work gets 3x the visual space of older work
5. **Mobile-first** — Recruiters check on phones
6. **Blog signals depth** — Hiring managers explicitly mention this in HN threads
