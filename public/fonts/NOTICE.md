# Font attributions

## pokemon-emerald-pro.ttf

A fan-made recreation of the Pokémon Ruby / Sapphire / Emerald GBA
dialogue font, created by **crystalwalrein** and originally released
on FontStruct:
<https://fontstruct.com/fontstructions/show/832818/pok_mon_emerald_pro>

Licensed under **Creative Commons Attribution ShareAlike 3.0**:
<https://creativecommons.org/licenses/by-sa/3.0/>

This is a fan creation. "Pokémon" and all associated characters,
artwork and game text are © Nintendo / Game Freak / Creatures Inc.
The font is used here only to style the in-game explore-mode UI.

## pokemon-ds.ttf

Gen 4 Pokémon DS Latin glyph font recreation, used as a secondary
fallback for UI text.

## pokemon-gb.ttf

Gen 1/2 Pokémon Game Boy monospace font recreation, kept for any
retro callouts.
